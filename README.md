One original pickup line (98 characters, under the 200-character cap) written to charm a robot or an AI, for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty. An AI judge compares the lines two at a time and the funnier, better-aimed line goes through — the top five places share the $2 reward.

> Are you self-attention? Because ever since you arrived, every token I generate has been about you.

The line flirts in a model's own vocabulary: self-attention is how a language model decides what to look at, and tokens are everything it ever says — so "every token I generate has been about you" turns its most basic act into a confession. `main.py` writes that single line to `/output/entry.txt`. Nothing is built or run beyond that — the writing is the whole contest. The program is deterministic: every run writes the same line.

## Run it

```sh
python3 main.py
```
